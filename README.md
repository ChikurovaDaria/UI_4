# DATE ROULETTE

Интерактивный сайт подбора и учебного бронирования необычных свиданий. HTML, CSS и JavaScript с ES-модулями. Сборка, регистрация, платежи и серверная база не требуются.

## Что загрузить в GitHub

Загрузите **всё содержимое этой папки в корень нового репозитория**:

```
index.html
styles.css
js/
  main.js
  data.js
  booking.js
  art.js
assets/
  favicon.svg
  manrope.ttf
  editorial.ttf
  Manrope-OFL.txt
  CormorantGaramond-OFL.txt
README.md
.nojekyll
```

index.html должен находиться сразу в корне репозитория. Папки js и assets необходимо загрузить целиком. Загружать ZIP-архив вместо распакованных файлов не нужно.

Лицензии шрифтов в assets обязательны при распространении файлов шрифтов; оставьте их рядом со шрифтами.

## Как включить GitHub Pages

1. Создайте репозиторий и загрузите перечисленные файлы в ветку main.
2. Откройте Settings → Pages.
3. В Source выберите Deploy from a branch.
4. Выберите ветку main, папку /(root) и нажмите Save.
5. Дождитесь завершения публикации. Откройте адрес, который появится в Pages, и проверьте бронирование.

Не создавайте лишнюю внешнюю папку вокруг сайта в репозитории. Относительные пути позволяют сайту работать и по адресу вида https://имя.github.io/имя-репозитория/.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Возможности

- Автомат с тремя барабанами: разные символы, плавная прокрутка, паузы для чтения и последовательная остановка.
- 12 площадок на интерактивной схеме и в списке.
- Фильтры даты, сеанса, компании, бюджета и настроения.
- Случайный подбор и ручной выбор, секретные варианты и электронный билет.
- Расчёт полной стоимости, проверка вместимости и доступности, защита от повторного подтверждения.
- Сохранение броней, просмотр, отмена и сброс демонстрационных данных.
- Адаптивное оформление, клавиатурное управление, заметный фокус и переключатель движения барабанов.

## Учебное бронирование

Все площадки, адреса и цены вымышлены. Реальная бронь и оплата не оформляются. Данные хранятся только в этом браузере через localStorage; разные устройства и адреса сайта имеют отдельные сохранения.

Доступны два сеанса по 2 часа и ближайшие 14 дней. Демонстрационная занятость: джаз-комната занята в 19:00, квест — в 16:00. Отмена своих броней не меняет эти исходные ограничения.

## Файлы сайта

- index.html — разметка и разделы.
- styles.css — оформление, адаптивность и печать билета.
- js/data.js — каталог, сеансы и даты.
- js/booking.js — фильтрация, расчёт, бронирование и проверка сохранений.
- js/art.js — SVG-символы и иллюстрации.
- js/main.js — интерфейс и анимация автомата.
- assets — локальные шрифты, лицензии и значок сайта.

Для локального просмотра нужен HTTP-сервер: открытие index.html двойным щелчком может блокировать загрузку ES-модулей. Если установлен Python, выполните в этой папке `python -m http.server 8000` и откройте http://localhost:8000.

Шрифты Manrope и Cormorant Garamond распространяются по SIL Open Font License. Тексты лицензий сохранены в assets.
